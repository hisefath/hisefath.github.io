# Portfolio visual system

The homepage uses a Daybreak-inspired amber signal horizon across the page and an interactive world skyline behind the hero copy. The palette is anchored by burnt orange `#804916`, near-black buildings, and restrained yellow-orange glow. The skyline includes New York City, Dallas, Austin, Seattle, London, Paris, Dubai, Kuala Lumpur, Sydney, and Shanghai, plus a domed masjid. The skyline ground line sits near the bottom of the hero on desktop and mobile. Foreground towers have narrow facade ribs, floor bands, side seams, selected amber-lit rooflines, and smaller 2×2 window panes per bay. Window tones vary independently and turn on and off slowly. A low amber backlight and height shading give the dark building layers more depth. About half the building forms show exposed columns, floor slabs, cross-braced bays, rear supports, and roof rebar; cranes have lattice masts and jibs, cabs, counterweights, cables, and hooks. Their upper structures sweep gently left and right around fixed masts while cables and hooks rise and fall at different slow phases. Crane depth stays fixed to avoid truss overlap flicker. The buildings use small triangles of varied sizes. Pointer proximity scatters a deterministic subset of faces. Longer beam segments reduce the full mesh from 9,952 to 7,952 faces; the moving subset is now 4,559 faces (previously 7,529), reducing GPU geometry and CPU work without removing building details. Holding expands the field; on release, a distance-based spring accelerates shards as they approach their original positions without overshooting. An opening burst assembles on page load, and a random burst occurs every 10–100 seconds while the hero is visible. Small amber line streaks accompany moving faces.

`index.html` owns the two canvases and preserves the portfolio's content and navigation. The hero stage is contained within the hero; the signal horizon remains page-wide. `css/portfolio.css` uses the dark amber city design. `js/portfolio.js` updates the copyright year. The source for the visuals is in `js/visuals-src/`; `js/portfolio-visuals.js` is the committed self-contained browser bundle. Static GitHub Pages hosting needs no build step.

To edit the effect, run `npm install`, change files in `js/visuals-src/`, then run `npm run build:visuals`. To preview locally, run `python3 -m http.server 8000` at the repository root and open `http://127.0.0.1:8000/`.

The skyline cancels its animation frame while offscreen or when the tab is hidden. Scrolling back restarts the opening scatter-to-assembly sequence. Active rendering is capped near 30 frames per second; idle rendering is slower. Both canvases cap pixel density at 1.25, the horizon runs near 15 frames per second, and WebGL antialiasing is disabled to reduce fill cost. Reduced-motion settings remain honored. If WebGL is unavailable, the hero displays the existing skyline SVG in a warm tone.
