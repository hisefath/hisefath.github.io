HOW I BUILD 005 / AI-NATIVE WORKFLOW

A system for building systems.

Software Factory Kit gives AI-assisted work a repeatable structure. I define the intent and make decisions at gates; agents handle bounded investigation, implementation, and tests; independent checks verify the result.

Read the workflow spec ↗
  1. 01 / DEFINE

    Product intent

    Sharpen the brief, gather evidence, and write requirements before implementation.

    sharpen-brief → write-prd
  2. 02 / DESIGN

    System boundaries

    Map the architecture, interfaces, acceptance criteria, and work slices.

    design-hld → slice-tasks
  3. 03 / BUILD

    Bounded execution

    Assign work to agents with explicit file ownership and a clear definition of done.

    implement-task
  4. 04 / VERIFY

    Independent evidence

    Run quality and security checks, review the diff, and record failures to improve the kit.

    verifier → route-failure
Where the human stays in the loop

Approval gates cover product intent, architecture, milestone decisions, and shipping. The repository documents the gates, skills, scripts, and the evolving failure log.
